# 出格 (Chū-Ge) · 品牌标志使用规范

> 店小秘发货导出助手 · 浏览器扩展图标
> 几何真源：`logo-master.svg`　版本 v1.0　构建器：`build.cjs`

---

## 1. 标志构成与含义

| | 内容 |
|---|---|
| 名称 | **出格** / CHU-GE |
| 构成 | ① 字形「出」的几何减笔　② 圆角底板（共 2 个元素） |
| 含义 | 「出」= 导出 / 出货 / 取出去，与工具唯一的动作同义；三竖栏 = 发货单的「行」，两横档 = 「格」 |
| 风格语法 | **圆端** —— 端帽与转角全部取满圆（r = SW/2），全局无直角、无锐角 |
| 元素预算 | 2（主角唯一；去底板图形仍成立，去中栏则语义丢失） |

**为什么不用箭头**：同类「导出」工具清一色「表格 + 向下箭头 / 云下载」，已构成视觉噪音。
本标志靠**字义**而非符号惯例传达导出，因此辨识度来自形态本身，不来自约定俗成的箭头。

## 2. 比例系统与构建参数表

比例系统：**整数比 · 模数 M = 8px**（画布 1024 = 128M）。所有关键尺寸均可代入复验。

| 参数 | 值 | 模数 | 说明 |
|---|---|---|---|
| 画布 | 1024 × 1024 | 128M | 主稿坐标系 |
| 底板圆角 | 224 | 28M | 圆角矩形底板 |
| 笔宽 SW | 128 | 16M | 端帽半径 = SW/2 = 64 = 8M |
| 竖栏心 x | 240 / 512 / 784 | 30M / 64M / 98M | 间距 272 = 34M |
| 中栏长 | 240 → 784 = 544 | 68M | 比侧栏多上探 64 = 8M |
| 侧栏长 | 304 → 784 = 480 | 60M | |
| 横档 y | 464 / 624 | 58M / 78M | 侧栏 480 三等分，每格 160 = 20M |
| 字形视觉外框 | 672 × 672 | 84M | 176 → 848 |
| 四边留白 | 176 | 22M | 上下左右等重 |

**尺寸链（可直接代入验证）**

```
竖栏外缘 176 → 848 = 672 = 84M
侧栏 304 → 784 = 480 = 3 × 160          ✔ 三等分
横档 464 / 624 → 304+160 / +160          ✔
字形外框 672 × 672，画布 1024 居中 → 四边留白 176，等重 ✔
留白 : 字形 = 176 : 672 = 1 : 3.818      （声明比值复算误差 0.0%）
```

**光学修正（3 处）**

1. **中栏上探 64（8M）** —— 令顶部不读成呆板横线，并给出「取出」的方向感；上探后中栏视觉顶点 = 176，与左右/下留白同值，四边留白等重。
2. **横档端帽与竖栏外缘相切** —— 横档画到栏心 240 / 784，圆头端帽 r=64 正好抵达 176 / 848，与竖栏外缘重合：端头不外凸、也不缺口。
3. **无 overshoot** —— 字形以横竖直线为主、无弧线外轮廓，不触发曲线越基线修正。

## 3. 净空区

**净空区 = 图标边长的 17.2%（即主稿内建留白 176 / 1024）。**

任何文字、图形、边框、容器边缘都不得进入该区域。主稿已把留白做进几何，
所以**直接使用 `logo-master.svg` 即天然满足净空要求**；若要与其他元素并置，
按上表在四周再退让同等距离（= 字形外框的 1/4 ≈ 168px @1024）。

## 4. 最小尺寸

| 场景 | 最小尺寸 | 说明 |
|---|---|---|
| 屏幕 · 浏览器工具栏 | **16px** | 已实测栅格化通过：读作「格」，不粘连成团 |
| 屏幕 · 应用图标 / 商店 | 48px | 推荐 128px 以上 |
| 印刷 | 8mm（图形高） | 小于此尺寸笔宽会低于印刷可分辨阈值 |

> 16px 时三栏两档会自然收拢成「格」的读感 —— 这与 Excel 的表格语义同向，属于**合理收拢**而非糊化。
> 不要为了「更清楚」而手动加粗：实测加粗会让缝隙闭合、反而更糊。

## 5. 禁用示例

| ❌ 禁止 | 原因 |
|---|---|
| 拉伸 / 压扁 / 非等比缩放 | 笔宽与留白比例立刻失真 |
| 旋转任意角度 | 字形语义依赖正立；旋转后不再是「出」 |
| 加描边 / 阴影 / 外发光 / 渐变 | 破坏圆端语法与单色可复现性 |
| 更换底色后仍用白形 | 浅底 + 白形对比不足（须改用变体 02 蓝形） |
| 拆散或重组三栏两档 | 几何是参数化整体，改动即破坏三等分与相切关系 |
| 把中文字标当作图形元素塞进底板 | 底板上只放字形，字标只出现在 Lockup 中 |
| 直接描摹字体里的「出」 | 本标志是原创几何减笔，不是字体描边 |

## 8. 复现指引

```bash
# 改了几何？只改 logo-master.svg，然后：
CHROME="<本机 chromium>" NODE_PATH="<node_modules>" node design/logo/build.cjs
# → 重新生成 variants/、icon/、public/icon/、preview.html

# 让扩展用上新图标：
npm run dev && npm run build      # public/ 会被原样拷进产物
# 再到 chrome://extensions / edge://extensions 刷新扩展
```

> 图标是**静态资源**（`public/icon/*.png`），不参与 content script 逻辑，
> 替换后不影响面板与导出功能；但扩展必须**刷新**（仅按 F5 不会重载图标）。
